# vuesp.lcd-2432S024C

Sunton/DIYmalls **ESP32-2432S024C**: ESP32, 2.4" 240×320 TFT, capacitive touch, microSD and a local Vuesp web interface.

Прошивка **5.0.0** PlatformIO + web UI **5.0.0** на Vue 3. Общие компоненты подключены как локальная file-зависимость `vuesp-components` из `../../../vuesp-components`.

## Что умеет

- экран диагностики: Wi-Fi/IP/RSSI, uptime, heap, touch, SD;
- несколько экранов с перелистыванием свайпом: диагностика, картинка и живые данные;
- загрузка картинок через браузер с предпросмотром, масштабом и перетаскиванием (WYSIWYG 320×240), хранение в LittleFS или на SD;
- текстовые метки на экране с подстановкой переменных и портов ScriptRunner;
- готовые примеры скриптов для экранов, тача и свайпов в Scripts;
- ёмкостный тач **CST820** (I2C);
- microSD: отдельный файловый менеджер рядом с LittleFS: список, папки, загрузка, скачивание, удаление и drag-and-drop между LittleFS и SD;
- подсветка: яркость 0–255, включение/выключение;
- ориентация: альбомная / альбомная перевёрнутая;
- встроенный RGB-светодиод (по умолчанию выключен), динамик, LDR, вход батареи;
- веб-страница **`/device/display/`**: экраны устройства;
- плитки dashboard: палитра, яркость, подсветка, ориентация, тач, SD, LDR, батарея, кнопка BOOT и beep;
- OTA-обновление по Wi-Fi, ScriptRunner, dashboard, файловая система LittleFS.

## Плата

| Параметр | Значение |
| --- | --- |
| MCU | ESP32, 4 МБ flash, 520 КБ SRAM |
| Экран | 2.4", 240×320, **ILI9341** |
| Тач | **CST820** (I2C) |
| SD | microSD, SPI |
| USB | USB-C, CH340 |
| RGB | R/G/B = GPIO4 / 16 / 17, active-low |
| Звук | DAC GPIO26, FM8002A |
| LDR / батарея | GPIO34 / GPIO35 |
| Кнопки | BOOT GPIO0, RESET |

Распиновка:

| Группа | Сигнал | GPIO |
| --- | --- | --- |
| Дисплей | MOSI / MISO / SCLK / CS / DC / BL | 13 / 12 / 14 / 15 / 2 / 27 |
| Тач | SDA / SCL / RST / INT | 33 / 32 / 25 / 21 |
| SD | CS / MOSI / MISO / SCK | 5 / 23 / 19 / 18 |
| RGB | R / G / B | 4 / 16 / 17 |
| LDR / батарея | ADC | 34 / 35 |
| Динамик | DAC | 26 |

Внешние разъёмы:

| Разъём | Контакты |
| --- | --- |
| P1 | `VIN`, `IO1/TX`, `IO3/RX`, `GND` |
| P3 | `GND`, `IO35`, `IO22`, `IO21` |
| CN1 | `GND`, `3V3`, `IO22`, `IO21` |
| P4 | динамик (выход FM8002A) |

Полная карта GPIO и список выводов, которые есть в GPIO-интерфейсе, — в [DOCS.md](DOCS.md#распиновка).

## Сборка

Если правится локальный `vuesp-components`, сначала соберите его `dist`:

```bash
cd ../../vuesp-components
npm run build
```

Затем веб-интерфейс устройства:

```bash
cd vue
npm ci
npm run protocol
npm run build-web

cd ..
~/.platformio/penv/bin/pio run -e esp32
~/.platformio/penv/bin/pio run -e esp32 -t buildfs
```

Прошивка и файловая система:

```bash
~/.platformio/penv/bin/pio run -e esp32 -t upload
~/.platformio/penv/bin/pio run -e esp32 -t uploadfs
```

Если экран пустой/белый или картинка «мусорная» — у платы может стоять **ST7789**. Для неё есть отдельное окружение:

```bash
~/.platformio/penv/bin/pio run -e esp32-st7789 -t upload
```

## Ограничения

- 4 МБ flash и нет PSRAM; локальный UI сделан на TFT_eSPI без LVGL. Полный кадр в RAM не помещается, JPEG декодируется блоками.
- SD-файловый менеджер работает через отдельный блок на странице File system; формат SD доступен в меню с подтверждением и стирает карту полностью.
- Ориентация локального экрана — только альбомная (обычная/перевёрнутая).
- RGB-светодиод активен низким уровнем; по умолчанию все каналы выключены.
- LDR и вход батареи отдаются как ADC-порты без калибровки.
- На экране до 8 экранов и до 8 меток на экран; шрифт TFT_eSPI — только ASCII, кириллица заменяется на `?`.
- Картинки хранятся как JPEG 320×240 (готовятся в браузере), лимит 300 КБ, примерно 20–40 КБ на кадр.
- `uploadfs` пересоздаёт LittleFS и стирает `/tmp/config.bin`, `/screens.cfg` и загруженные картинки. Для обновления только веб-интерфейса заливайте файлы через `POST /fs`.
